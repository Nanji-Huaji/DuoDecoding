## 已证实的旧故障

`L=b+c`、`gamma_cap=64`，以下均为合法参数：

| alpha | L | 精确离散最优 gamma | 旧结果 |
| --- | --- | --- | --- |
| 0.5 | 0.001 | 8 | 固定 Lambert 区间导致 gamma=1 |
| 0.5 | 0.0005 | 9 | 根参数下溢到 -0，抛异常 |
| nextafter(1,0) | 0.999999 | 64 | 根参数舍入到 -1/e，抛异常 |

最初的三个回归全部失败，修复后通过。独立枚举还检出了浮点分数平台与
`alpha=1,L>=1` 的旧边界问题；这些不是移动模块造成的差异。

## 同一目标，改用稳定的离散优化

仍优化既有目标：

`S(g)=sum(alpha**j, j=0..g)/(1+g*L)`，整数 `1<=g<=gamma_cap`。

令 `D_g=alpha**(g+1)*(1+gL)-L*sum(alpha**j,j=0..g)`。
它与 `S(g+1)-S(g)` 同号，且在 `0<alpha<1,L>0` 上

`D_(g+1)-D_g=-(1-alpha)*alpha**(g+1)*(1+(g+1)*L)<0`。

因此指数扩张区间、再二分找到第一次不再增长的位置即可；不枚举 cap，
也不通过相邻已舍入的 float 分数判定最优点。

- 输入 alpha 与成本是精确的 binary64 数值；`L` 明确取普通浮点 `b+c` 的结果。
- 比较等价于 `alpha**(g+1)>L/[L+(1-alpha)*(1+gL)]`。
- 小指数用精确整数交叉比较；较大指数用逐次乘法均定向舍入的 Decimal
  上下界及重复平方。区间重叠时增加精度，不加决策 epsilon。
- 在区间细化前用约分后的有理数检查精确相等，避免真平局导致无限细化。
- 目标比较次数为 `O(log cap)`；单次比较的精度成本与输入有关，不宣称常数成本。
- 实数目标平局取较小 gamma；这是明确的约定，不是把 float 平台当作真平局。

报告分数采用 80 位 Decimal 中间算术后转 float，避免几何和相消与
`gamma*L` 的 binary64 中间溢出。报告值仍是近似值，极端时可以舍入到
1、下溢到 0 或溢出到 infinity；它不再决定搜索方向。

## AS² 与边界

存在 `S(g)>1` 当且仅当 `alpha>L`：`S(g)>1` 等价于
`alpha**1..alpha**g` 的平均值大于 L，其最大平均值由 `g=1` 取得。
AS² 直接判断这个条件。因此极小正收益可能返回 `use=True, score=1.0`，
这不是自相矛盾，而是报告分数舍入。

- `alpha=0,L=0`、`alpha=1,L=1`：全部候选同分，取 gamma=1、standalone。
- `alpha=1,L>1`：取 gamma=1；不再无条件取 cap。
- `L=0,alpha>0` 或 `alpha=1,L<1`：取 cap。
- 明确拒绝非有限估计、越界接受率、负成本、溢出的 `b+c`，以及非正或非整数 cap。
  这是有意收紧旧的静默夹取行为。标量分数 API 仍允许 gamma=0，但不接受负数或浮点伪整数。
- Decimal 上下文独立创建，不受调用者精度、舍入方向或 Inexact trap 影响，也不泄漏设置。

## Lambert 兼容函数

`_lambert_w_minus_one` 不再参与 ODLD，但保留供已有调用者使用。
以 `t=-w>=1` 解 `t-ln(t)=-ln(-z)`，使用 Decimal 保护位与输入相关区间，
避免直接计算下溢的 `w*exp(w)`。开放定义域不变；浮点的 `-1/math.e`
位于真实边界外，仍被拒绝。不再声称 float 返回值有 `1e-28` 绝对精度。

## 独立证据

Lead 的不可变输入集与探针保存在忽略的本地取证目录，不是运行时依赖。
公共回归测试不依赖 mpmath，也不依赖这些私有文件。

- **3,246** 组小 cap：精确 dyadic 整数枚举每个目标值，gamma 和 AS² 全部匹配。
- **2,112** 组标量：独立 Decimal180 参考，最大差异 **1 ULP**。
- **5** 组大 cap：mpmath800 对目标分数做不同的三分搜索并枚举最终区间，全部匹配。
  包含 cap=`10**100`、最优 gamma=`6374424378296831398`；没有 cap 规模的枚举。
- `alpha=.5,L=2**-1074` 的最优 gamma 为 **1073**，即使附近 float 分数都为 2。
- **163** 个 Lambert 输入（含分支点相邻数、最小 subnormal）：与 mpmath160
  参考的 float 值一致；这是实测结果，不是任意精度承诺。
- 最初三例、AS² 的三个近 1 分数案例、Lambert 的三个极端案例均经历红→绿。
- 公共测试还覆盖精确 Fraction 枚举、成本求和口径、边界、无效输入、上下文隔离，
  以及有超时保护的大 cap 调用。最终整批门禁见[联合报告](<tk_slt_wire_odld_20261111.md>)。
