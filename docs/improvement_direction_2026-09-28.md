## 三、批次 `bash-65` 结果（已落地 2026-09-28）

- **A**: θ\*(temp0.7)=0.8；θ\*(temp0)≥0.95（阶梯仍升：tf 5.32@0.8 → 5.79@0.95，计数指标）
  - ⚠️ 窗口审计：temp0 阶梯 θ∈{0.4,0.8} 跑于 lqf 52-95% util 窗，θ0.95 起干净——**θ 间 Thr 不可比**，判定仅凭 tok/fwd
- **B**: γ8/16/32 → tf 4.46/4.64/4.44——**停机规则绑定，γ 非约束**，γ16 定稿
- **C**: 干净窗基线（temp0.7, N=40）：DSD **11.58**（污染窗 9.54）、DSSD **10.06**（旧 8.26）；
  计数指标两窗逐位相同（免疫性实证）；DSD 真实采样降幅 −8.7%（vs t5a 12.68）；
  **CEE-SD(θ0.8)/DSD = 1.91×**（temp0 时 1.76×，采样域领先扩大）
- **D**: isotonic 留出 Brier：t0 −37%，t07 −51%；remap 见 `exp/arp_calib_remap.json`
- 尾批：**target 锚落地**（N=80 干净窗，acc 0.1625，Thr 21.76）：
  - 分布保持性检验（两样本 σ）：DSD 0.17σ ✓ / DSSD 0.17σ ✓ / CEE-SD 0.52σ ✓ —— 投机方法 acc 全部跟踪锚；
  - **CUHLM 0.000 偏离锚 2.27σ ✗** —— 崩溃的第三条独立证据线，统计确认；
  - target 纯本机（无通信）Thr 21.76 vs CEE-SD 22.14（带 100ms/轮 WAN 计费）——摊薄跑赢零延迟本机，但 **+1.7% 且跨窗**，同窗复跑进批次3（SpecEdge 式 headline 需要同窗数字）；
  - temp0.7 采样惩罚锚定：0.2375 → 0.1625（−7.5pp，GSM8K）。
- 尾批补充：**θ0.99@temp0 → tok/fwd 5.91，草稿 15.87（γ16 顶格）**——temp0 阶梯完整：
  4.26(θ0.4) → 4.82 → 5.32 → 5.79 → **5.91(θ0.99, 仍升, 被γ截断)**
  - **结构性洞察：ARP 早停的价值是温度条件化的**——temp0 最优停机杠杠（raw 0.01, 校准后≈0）
    实际是"从不停"（草稿顶到 γ 上限）；temp0.7 最优停在真值 0.71。机理：贪心域
    草稿位成本 ~3ms vs 接受省 ~110ms 目标前向，边际接受率 3% 也回本；采样域 TVD
    惩罚让长尾投机亏。
  - 推论 1：cumulative 时代 temp0 表把 tok/fwd 压掉 ~25%（3.88 vs 5.91）——
    旧几何上界分析需在 per_token 语义下重做；
  - 推论 2：ARP 章节正确叙事 = "temp>0 的守门人"（temp0 下退化为 γ 定长草稿器）；
  - γ16@θ0.99 顶格 ⇒ E1(γ32) 在测 γ 轴是否继续打开。
